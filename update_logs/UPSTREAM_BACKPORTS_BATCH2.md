# 第二批上游优化：保存、离线字体与 Markdown

在 `feature/electron-offline` 的现有未提交工作上继续实现。参考 Reactive Resume v6.1.1 的保存恢复、字体镜像及 Markdown 导出思路，适配现有 React、NestJS、SQLite 和 Electron 架构。

## 保存防丢失

- 每份简历单独排队，串行发送请求，合并尚未发送的后续编辑，避免不同简历共享防抖计时器。
- 保存有明确状态及重试入口。离开编辑器、打印和导出前可等待队列排空；保存请求有超时。
- 正文变更同步写恢复草稿，携带简历 ID、独立 token、保存基准和编辑时间。Electron 写入用户数据目录，使用临时文件、fsync 和原子重命名；旧保存响应只能删除 token 一致的草稿。
- 浏览器模式使用本机浏览器存储，Electron 模式使用磁盘，重启端口变化不会隔离桌面草稿。
- 重开时明确选择恢复为副本、下载草稿或丢弃。恢复不会覆盖原简历，服务器内容较新时有提示。
- 导航失败时可重试、继续编辑，或在草稿确已落盘时保留草稿离开。桌面退出握手同样只在确认保存或草稿持久化后允许退出。
- 加载服务器内容不会触发保存；撤销、重做会进入保存队列。恢复后的外部内容同步到已挂载的富文本编辑器。

## 离线字体库

- Typography 提供显式下载、检查、已缓存和重试状态。仅准备接口联网；状态、CSS 和字体文件接口只读缓存。
- 下载选定的字体，并补全目录中可用的常规、粗体、斜体和粗斜体；保留来源、原始许可证及 SHA-256 校验清单。
- 缓存位于 `STORAGE_DIR/font-cache`，桌面端由运行环境映射至应用用户数据目录，重启复用。
- 画布与 PDF 都读取本机同源 CSS，保留自定义上传字体和变量字重。字体下载完成后通知画布刷新。
- 缺少缓存时明确说明使用替代字体；许可证取得失败时给出独立提示。读取缓存不自动回退到 Google 网络请求。
- 此次实际下载验证使用 Lato 的 regular、700、italic、700italic。没有预装或批量下载整个字体目录。

## Markdown 与导出

- 按实际布局顺序输出可见章节及条目，支持自定义章节、链接、强调、嵌套列表与编号起点。
- 排除私人笔记、照片、隐藏条目及未排版内容。
- PDF 需要保存成功；JSON、Markdown 在保存失败时仍允许备份最新本机内容，并显示提示。
- 导出等待结束后重新读取当前简历，防止使用旧闭包快照或下载已切换的简历。
- 浏览器可直接下载，Electron 复用本地保存对话框。桌面 data URI 显式解码，保留中文和特殊字符；远程下载成功后才写入目标文件。
