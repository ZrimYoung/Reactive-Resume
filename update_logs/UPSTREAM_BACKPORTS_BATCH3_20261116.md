## 功能

1. 图片上传按请求、简历 ID、原 URL 和当前锁定状态确认归属；离开或切换简历后旧回调失效。同一文件可再次选择重试。
2. JSON Resume 接受空日期并校验真实日历日期，保留工作/志愿经历 highlights、教育 courses、项目及证书链接。缺失日期不生成 `undefined`，未命名项目保留内容并显示中性占位名称。文本转换为富文本时转义 HTML。桌面原生文件选择与普通文件选择使用同一解析流程；验证绑定文件、格式与请求代次，关闭、重置、换文件或换格式会使旧结果失效。
3. 副本名称与 Unicode 标识自动编号，数据库唯一约束配合重试处理并发复制。手动命名不被静默改写。保存后同步简历库缓存，避免回库复制旧正文；新建时未手动编辑或锁定的标识跟随完整标题，而不是停在首字。
4. 经历、教育、项目、出版物等支持主动一键按日期排序：持续经历优先，随后日期倒序；未知日期保持原文及相对次序并放在末尾提示。通过现有 store 保存，支持撤销。
5. `?` 快捷键帮助与 Ctrl/Cmd 加滚轮光标锚点缩放。输入框、富文本、输入法组合和其他弹层期间不抢快捷键；iframe 消息核对来源。
6. 保存采用 SQLite 原子 compare-and-swap，携带 `expectedUpdatedAt`，时间戳严格递增；无版本或陈旧版本返回明确 409。冲突时暂停自动覆盖，保留本机修改，支持另存副本后加载已存版本。内容与锁定等元数据共用协议，锁定状态禁止正文和撤销/重做入队。磁盘和浏览器草稿按会话隔离，兼容旧单文件草稿，恢复界面可选择不同草稿，清理仅匹配 token。
7. 本机生成 DOCX 与 ODT，两个导出器按需加载，共享 v4 可打印内容模型。支持标准和自定义章节、隐藏/布局过滤、中文、链接、富文本、嵌套及有序列表、纸张与显式分页；排除私人笔记和照片。沿用保存队列、失败时最新本机备份与桌面保存 IPC。界面说明这是简化的可编辑排版。
